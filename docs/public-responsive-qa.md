# Public responsive QA

Phase 11 public pages were checked against the shared production gate and reviewed for mobile layout behavior.

## Routes covered

- `/`
- `/our-story`
- `/history`
- `/first-visit`
- `/events`
- `/faq`
- `/rules`
- `/policies`
- `/resort-map`
- `/gallery`
- `/stays-and-rates`
- `/contact`
- `/book`

## Criteria

- Header collapses into the mobile menu below desktop navigation width.
- Public footer links remain readable without horizontal clipping on narrow screens.
- Cards and content grids collapse to a single column before tablet widths.
- Resort map remains usable on mobile through horizontal scrolling and a visible swipe cue.
- Forms preserve labeled controls, visible status/error text, and reachable submit buttons on mobile.
- Public media and CMS sections use fluid widths and avoid viewport overflow outside intentional map scrolling.
