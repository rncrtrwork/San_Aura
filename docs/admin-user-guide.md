# Staff admin user guide

This walkthrough closes the Phase 14 staff training item. Use it during staff onboarding and the soft-launch trial.

## 1. Overview

- Start each shift on `/admin`.
- Review occupancy, arrivals, departures, weekly revenue, upcoming arrivals, tasks, and recent activity.
- Use the Privacy First banner as the reminder that guest photography is not allowed.

## 2. Reservations

- Use status tabs to move between pending, confirmed, checked-in, completed, and cancelled stays.
- Create new reservations from the guest/member lookup flow.
- Use the reservation side panel for booking details, payment summary, internal notes, confirmation sending, and check-in.
- Check-in follows the property check-in time from Settings.

## 3. Calendar

- Use month, week, and timeline views to confirm site availability.
- Open a day cell for arrivals, departures, and occupancy details.
- Use the availability summary before confirming a stay.
- Add blocked dates when maintenance or staffing requires holding sites back.

## 4. Events

- Create draft events with title, date, location, capacity, registration details, description, and image.
- Upload event images only after confirming the image contains no identifiable people.
- Publish events when they are ready for the public Events page.
- Watch registration counts and capacity before accepting walk-ins.

## 5. Stays & Rates

- Edit cabin, RV, and tent stay cards from the Stay Types tab.
- Keep base rate, weekend rate, extra guest fee, minimum stay, and cleaning fee current.
- Use seasons for named date-range overrides.
- Keep add-ons active only when staff can fulfill them.

## 6. Resort Map

- Use the map for site status: available, occupied, maintenance, or blocked.
- Open site details to review amenities, current stays, maintenance notes, and next availability.
- Use Edit Map mode only for approved map corrections.
- Keep public map status accurate because guests can view the read-only version.

## 7. Gallery

- Upload images, video, and documents into the correct album or usage group.
- Confirm every public-facing image contains no identifiable people before approval.
- Add descriptive alt text before publishing media to the website.
- Archive assets instead of deleting when staff may need a historical reference.

## 8. FAQ & Rules

- Use the FAQ, Resort Rules, and Policies tabs for public-facing guidance.
- Keep categories organized so guests can find check-in, pets, privacy, and stay rules quickly.
- Use draft status for incomplete copy.
- Review SEO title and meta description before publishing high-traffic pages.

## 9. Website Content

- Edit public pages from the Pages list.
- Use hero, rich text, timeline, CTA, and gallery sections to build pages.
- Preview draft content before publishing.
- Use the History page timeline for resort history updates.

## 10. Settings

- Keep property name, logo, address, phone, email, timezone, check-in, checkout, and key-return times current.
- Review booking defaults before each season.
- Keep privacy and safety toggles aligned to resort policy.
- Manage staff access by role and deactivate former staff promptly.
- Use the Payments tab for PayPal-link-only MVP instructions.

## Member portal support

- Direct members to `/member` for balance, payment history, electric billing, documents, emergency contact, and membership details.
- Staff notes are never shown in the member portal.
- Members can request updates, but staff must still make official record changes.

## Training checklist

- Staff can log in and find the Overview dashboard.
- Staff can create and find a reservation.
- Staff can check the Calendar and Resort Map before confirming a stay.
- Staff can create or edit an event.
- Staff can update stays and rates.
- Staff can upload media and explain the no-people rule.
- Staff can publish FAQ/rules/content changes after preview.
- Staff can find member payments, documents, electric readings, and notes.
- Staff can explain the member portal boundaries.
- Staff can find Settings, staff roles, and the Activity Log.
